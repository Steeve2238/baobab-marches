# Comment imprimer un devis, une facture ou un BL sans en-tête/pied de page du navigateur

Quand vous imprimez un document depuis Baobab Marchés, votre navigateur ajoute automatiquement, en haut et en bas de la page imprimée, une ligne avec le titre de la page, l'adresse du site, la date et le numéro de page. C'est un réglage du navigateur (pas du document), il suffit de le désactiver **une seule fois** — le choix reste ensuite mémorisé pour les impressions suivantes.

## Google Chrome / Microsoft Edge (les plus courants)

1. Ouvrez le document, puis lancez l'impression (`Ctrl+P` sur Windows, `Cmd+P` sur Mac, ou le bouton "Imprimer" dans l'application).
2. Dans la fenêtre d'impression, cliquez sur **"Plus de paramètres"** (en bas de la liste des options).
3. Décochez la case **"En-têtes et pieds de page"**.
4. Cliquez sur **Imprimer**.

Ce réglage reste actif pour les prochaines impressions sur ce même ordinateur/navigateur — vous n'avez besoin de le faire qu'une seule fois.

## Mozilla Firefox

1. Ouvrez le document, puis `Ctrl+P` / `Cmd+P`.
2. Cliquez sur **"Mise en page"** ou l'icône d'engrenage, puis sur l'onglet **"En-têtes / pieds de page"**.
3. Mettez chaque champ (haut gauche, haut centre, haut droite, bas gauche, bas centre, bas droite) sur **"--vide--"**.
4. Validez, puis lancez l'impression.

## Safari (Mac)

1. Ouvrez le document, puis `Cmd+P`.
2. Dans la fenêtre d'impression, cliquez sur **"Afficher les détails"** si nécessaire.
3. Les en-têtes/pieds de page de Safari se gèrent via **Réglages de la page** (menu Fichier > Format d'impression) — décochez toute option d'en-tête/pied de page si présente.

## En résumé

- Cette étape ne prend que quelques secondes et n'est à faire **qu'une seule fois par ordinateur/navigateur**.
- Une fois fait, seul le document (devis, facture ou bon de livraison) apparaît sur la page imprimée, avec le nom et le logo de votre entreprise — sans aucune mention d'un tiers hébergeur.
